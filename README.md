## 网络速度与路由测试（重点）

这部分是保加利亚 VPS 评测的核心，很多人最关心的就是：**从国内访问它，到底快不快、路由绕没绕？**

### 国内 Ping 延迟

国内平均延迟约 **237～241ms**，这是正常的欧洲机房水平，不是优化线路，延迟没法和 CN2 GIA 比，但在普通欧洲机房里算正常发挥。

### 三网去回程路由

| 运营商 | 去程 | 回程 |
| --- | --- | --- |
| **电信** | 电信 163 骨干网 → 德国法兰克福 → Cogentco → 保加利亚 | GTT → 阿姆斯特丹 → 电信 163 直连 |
| **联通** | AS4837 → 圣何塞（绕美国）→ Telia → 欧洲 → 保加利亚 | 德国 → 西班牙 → 圣何塞 → 联通 AS4837 |

**结论**：
- 电信和移动基本上去回程都在欧洲内部直连，路由相对干净
- 联通去程绕到了美国西海岸才转欧洲，有明显的绕路，这是联通机器的老毛病
- 整体来说，**除联通去程绕美之外，三网回程基本都是欧洲直连**，对于欧洲非优化线路机房来说，路由表现算良好
